# NeoWorld-3: Agentic World Authoring with Tunable Geometry Programs

[English](README.md) · [项目主页与演示](https://neoworldproject.github.io/Studio/) · [NeoSDK](https://github.com/NeoWorldProject/NeoSDK)

**NeoWorld Studio** 是 NeoWorld-3 框架的应用实现。它从视觉观测中重建物体与场景，
将结果表示为可调参数的几何程序，在渲染预览和三维资产之外保留可编辑的构造逻辑、
命名参数与部件结构。

> **项目介绍版本。** 本版仅包含说明文档，不包含实现源码或可安装的应用。

## 从观测到可编辑世界

NeoWorld-3 将智能体构造与数值优化结合起来。智能体查看观测、编写几何程序、渲染结果，
并修改程序结构；几何工具根据观测视图拟合程序暴露的参数与物体位姿。共享参数表达部件间
的关系，让修改保留程序中编码的尺寸与连接约束。

流程由三个组件协作完成：

| 组件 | 职责 |
| --- | --- |
| **NeoWorld Studio** | 协调物体与场景重建、任务状态和用户反馈。 |
| **NeoMCP** | 将观测、源码编辑、渲染、测量和优化提供为智能体工具。 |
| **[NeoSDK](https://github.com/NeoWorldProject/NeoSDK)** | 提供几何构造、原生执行、检查与参数优化能力。 |

## 框架能力

- **物体与组合场景：** 根据视觉参考构造单个资产，并组装到共享场景中。局部编辑可以更新
  某个部件、物体或其位姿，同时保留周围的构造。
- **可调几何程序：** 显式保留构造、参数与位姿，让结构编辑和数值拟合作用于同一份
  可编辑表示。
- **可微优化：** 支持的程序在张量几何孪生中求值并批量光栅化。搜索前检查原生几何与孪生
  的一致性；Blender 用于基线和选定候选的物化，并提供原生渲染。
- **几何与关节检查：** 检查原生几何和提出的关节关系。配置后的物理反馈可提出有界刚体
  修正，再进行几何与视觉检查。
- **可选递归自改进：** 研究扩展根据已完成任务的执行记录开发可复用工具候选。候选经
  开发检查后进入临时开发库；运行中的任务保持固定工具快照。

场景委派与度量尺度校准仍属实验功能。递归自改进是可选扩展，普通任务默认关闭。
关节假设取决于现有证据；任务完成或几何准入本身不代表重建质量或物理有效性已得到验证。
